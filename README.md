# 📚 Book Library

A personal book collection manager built with React.

**Live demo:** https://library-theta-five-95.vercel.app

## Features
- Add, edit and delete books
- Search by title or author
- Filter by genre and reading status
- Reading statistics (total, read, unread)
- Data saved in localStorage
- Discover Books placeholder page
- Instructor feedback with a 1–5 rating

## Built with
React, Vite, JavaScript, CSS, localStorage, Formspree

## Run locally
npm install
npm run dev
